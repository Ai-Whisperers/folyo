# Profile Images

Place your profile picture here. The template supports:
- JPG, PNG, or WebP formats
- Recommended size: 400x400 pixels or larger (square)
- Recommended file size: < 500KB

## Naming Convention

You can name your profile picture anything, but update the reference in `_data/data.yml`:

```yaml
sidebar:
  avatar: profile.jpg  # Update this to match your filename
```

## Example

1. Add your image: `assets/images/my-photo.jpg`
2. Update `_data/data.yml`: `avatar: my-photo.jpg`
3. Commit and deploy
