## 🛠️ Tech Stack

This CV is built with:
- **Jekyll** - Static site generator
- **GitHub Pages** - Hosting
- **YAML** - Data configuration

---

## 📝 How to Update

1. Edit `_data/data.yml` with your information
2. Replace `assets/images/ProfilePicKyrian.jpg` with your photo
3. Update `assets/images/kikiresume.pdf` with your PDF resume
4. Commit and push - GitHub Pages will auto-deploy

---

## 🚀 Local Development

```bash
# Install dependencies
bundle install

# Run locally
bundle exec jekyll serve

# Open http://localhost:4000/kiki/
```
