A modern, responsive, and customizable Jekyll template for creating professional online CVs and portfolios. Based on a real-world professional CV, this template has been carefully crafted to help you showcase your skills and experience effectively.

## ✨ Features

- **📱 Fully Responsive** - Looks great on desktop, tablet, and mobile
- **🎨 Multiple Themes** - 8 color schemes to choose from
- **⚡ Fast Loading** - Optimized static site generation
- **🔍 SEO Optimized** - Built-in meta tags and structured content
- **📊 Analytics Ready** - Google Analytics integration
- **📄 PDF Export** - Link to downloadable resume
- **🎯 Professional Design** - Clean, modern layout perfect for job applications

## 🚀 Quick Start

### Method 1: GitHub Template
1. Click "Use this template" button above
2. Name your repository (e.g., `your-username.github.io`)
3. Clone your new repository
4. Follow customization steps below

### Method 2: Fork
1. Fork this repository
2. Clone to your local machine
3. Install dependencies: `bundle install`
4. Run locally: `bundle exec jekyll serve`

## 📖 Customization Guide

### Step 1: Basic Configuration
Edit `_config.yml`:
```yaml
title: "Your Name - Online CV"
url: 'https://yourusername.github.io'
baseurl: '/your-repo-name'
description: "Your professional tagline"
theme_skin: teal # Choose your theme
```

### Step 2: Personal Information
Edit `_data/data.yml` with your details:
- Personal information and contact details
- Professional summary and career profile
- Work experience and achievements
- Education and certifications
- Skills and proficiencies
- Projects and portfolio items

### Step 3: Assets
- Add your profile picture to `assets/images/`
- Add your resume PDF (optional)
- Update file references in `data.yml`

## 🛠 Development

### Prerequisites
- Ruby 2.7+
- Bundler gem
- Git

### Local Setup
```bash
# Clone the repository
git clone https://github.com/yourusername/online-cv-template.git
cd online-cv-template

# Install dependencies
bundle install

# Run locally
bundle exec jekyll serve --livereload

# Visit http://localhost:4000
```

## 🚀 Deployment

### GitHub Pages (Recommended)
1. Push your code to a GitHub repository
2. Go to Settings > Pages
3. Select source: "Deploy from a branch"
4. Choose `main` branch
5. Your site will be live at `https://yourusername.github.io/repo-name`

### Custom Domain
1. Add a `CNAME` file with your domain
2. Configure DNS settings
3. Enable HTTPS in GitHub Pages settings

### Other Hosting
This is a standard Jekyll site and can be deployed to:
- Netlify
- Vercel  
- AWS S3
- Any static hosting service
